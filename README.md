# Video Controller

![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)
![Safari](https://img.shields.io/badge/Safari-macOS-0a84ff.svg)
![Chrome](https://img.shields.io/badge/Chrome-Manifest%20V3-34a853.svg)

Video Controller 是一款適用於 Safari（macOS）與 Chrome 的瀏覽器擴充功能，可控制網頁上正在播放的影片或音訊，提供播放速度、音量增益及立體聲轉單聲道等功能，並提供工具列面板與影片浮動面板兩種圖形化操作介面。

## 功能特色

- **播放速度**：可調整範圍為 0.1× 至 16×，提供滑桿（對數刻度）、常用倍速按鈕及微調按鈕。
- **音量增益**：可調整範圍為 0% 至 400%，刻度可直接點選跳至指定音量。
- **立體聲轉單聲道**：將左、右聲道混合後同時輸出至兩側，適用於單耳聆聽或聲道不平衡的影片。
- **雙介面設計**：
  - **工具列面板**：點選瀏覽器工具列圖示開啟。
  - **影片浮動面板**：滑鼠移至影片上方時顯示於影片角落，展開後可進行完整操作，並支援網站自身的全螢幕模式。
  - 可於設定頁選擇同時使用兩者，或僅使用其中一種。
- **鍵盤快捷鍵**：所有按鍵皆可自訂，於輸入框中輸入文字時自動停用。
- **不保留播放設定**：重新整理或切換頁面（包含 YouTube 等單頁應用程式切換影片）後，自動恢復為 1×、原始音量及立體聲；「全部重設」亦會將影片音量還原為調整前的數值。

| 功能 | Safari（macOS） | Chrome |
| --- | :---: | :---: |
| 播放速度 0.1×–16× | ✅ | ✅ |
| 音量 0%–100% | ✅ | ✅ |
| 音量 100%–400% | ⚠️ 僅限一般影片檔 | ✅ |
| 立體聲轉單聲道 | ⚠️ 僅限一般影片檔 | ✅ |
| 工具列面板／浮動面板 | ✅ | ✅ |
| 鍵盤快捷鍵 | ✅ | ✅ |

⚠️ Safari 不允許擴充功能處理以 MSE 串流方式播放的影片聲音（YouTube 等多數影音網站皆採用此方式），詳見[已知限制](#已知限制)。

其他 Chromium 核心瀏覽器（如 Microsoft Edge、Brave）通常亦可依 Chrome 的方式載入。

## 安裝

本擴充功能尚未上架至 App Store 或 Chrome 線上應用程式商店，請依下列方式自行安裝。

### Chrome

1. 下載或複製（clone）本專案。
2. 於網址列輸入 `chrome://extensions`。
3. 開啟右上角的「開發人員模式」。
4. 點選「載入未封裝項目」，選擇專案中的 `extension` 資料夾。
5. 點選工具列的拼圖圖示，將「Video Controller」釘選至工具列。

### Safari：建置 App（建議）

**需求**：macOS、Xcode，以及一組 Apple ID（免費帳號即可）。

1. 自 App Store 安裝 Xcode，並將其設為使用中的開發工具：

   ```bash
   sudo xcode-select -s /Applications/Xcode.app/Contents/Developer
   ```

2. 於 Xcode ▸ Settings ▸ Accounts 登入 Apple ID。
3. 於專案根目錄執行建置腳本：

   ```bash
   ./scripts/build-xcode.sh
   ```

   腳本會將 `extension` 轉換為 Xcode 專案並完成建置，產出位於 `xcode/build/Build/Products/Release/Video Controller.app`。
4. 開啟產生的 `Video Controller.app` 一次。
5. 於 Safari ▸ 設定 ▸ 延伸功能 中啟用「Video Controller」。
6. 首次於網站上使用時，依提示允許擴充功能存取該網站。

#### 簽署方式

建置腳本預設使用 Xcode 中登入的第一個開發團隊進行簽署，可透過環境變數 `TEAM_ID` 調整：

| 指令 | 簽署方式 | 備註 |
| --- | --- | --- |
| `./scripts/build-xcode.sh` | 自動使用 Xcode 中的開發團隊 | 建議使用，重新啟動 Safari 後仍保持啟用 |
| `TEAM_ID=XXXXXXXXXX ./scripts/build-xcode.sh` | 指定開發團隊 | 適用於擁有多個團隊時 |
| `TEAM_ID=none ./scripts/build-xcode.sh` | 本機簽署（不使用 Apple ID） | 需於 Safari ▸ 設定 ▸ 開發者 勾選「允許未簽署的延伸功能」，且每次重新啟動 Safari 後須再次勾選 |

使用免費帳號（Personal Team）簽署的版本僅供本機使用；若需散布給他人，須具備付費的 Apple Developer Program 帳號。

### Safari：暫時載入（免 Xcode）

適合快速試用，不需要建置 App：

1. 於 Safari ▸ 設定 ▸ 進階 中勾選「顯示網頁開發者功能」。
2. 於 Safari ▸ 設定 ▸ 開發者 中點選「加入暫時性延伸功能…」，選擇專案中的 `extension` 資料夾。

暫時性延伸功能會於 Safari 結束或 24 小時後自動移除。

## 使用方式

### 工具列面板

點選工具列上的 Video Controller 圖示即可開啟，面板會顯示目前分頁偵測到的影片及其播放狀態。

- **播放速度**：拖曳滑桿、點選倍速按鈕或滑桿下方刻度，亦可使用 −／+ 按鈕或於滑桿上捲動滑鼠滾輪微調。
- **音量**：拖曳滑桿，或點選 0%、100%、200%、300%、400% 刻度直接跳至該音量；超過 100% 時滑桿會以橘色標示。
- **立體聲轉單聲道**：切換開關即可。
- **全部重設**：恢復 1×、原始音量及立體聲。
- 點選右上角齒輪圖示可開啟設定頁。

### 影片浮動面板

將滑鼠移至影片上方時，影片角落會顯示目前的倍速；若已調整音量或開啟單聲道，亦會一併顯示標籤。將滑鼠移至標籤上可展開完整控制面板。

### 鍵盤快捷鍵

快捷鍵僅於頁面中有影片時生效，於輸入框中輸入文字時自動停用。

| 預設按鍵 | 動作 |
| --- | --- |
| `S` | 減速 |
| `D` | 加速 |
| `R` | 於 1× 與上次使用的倍速之間切換 |
| `Q` | 音量 −10% |
| `W` | 音量 +10% |
| `N` | 切換單聲道 |
| `⇧ Shift` + `R` | 全部重設 |
| `V` | 顯示／隱藏浮動面板 |

倍速於 4× 以下每次調整 0.25×，4× 以上每次調整 1×；調整幅度可於設定頁變更。

### 設定

於工具列面板點選齒輪圖示，或於瀏覽器的擴充功能管理頁開啟設定頁。設定會自動儲存，可調整項目如下：

| 項目 | 選項 |
| --- | --- |
| 控制介面 | 兩者皆使用／僅工具列面板／僅影片浮動面板 |
| 浮動面板位置 | 左上／右上 |
| 浮動面板自動隱藏 | 開啟時，滑鼠離開影片或靜止 2.5 秒後隱藏 |
| 鍵盤快捷鍵 | 啟用／停用，以及自訂各項動作的按鍵 |
| 倍速調整幅度 | 0.05×／0.1×／0.25×／0.5× |
| 音量調整幅度 | 5%／10%／25%／50% |

## 已知限制

- **Safari 無法處理串流影片的音訊**：YouTube 等多數影音網站以 MSE（Media Source Extensions）串流播放影片，而 Safari（WebKit）不會將此類影片的音訊傳遞給 Web Audio API，亦不支援 `HTMLMediaElement.captureStream()`。因此在 Safari 中，此類影片僅能於 0%–100% 範圍內調整音量，無法放大超過 100% 或轉換為單聲道；擴充功能偵測到此情況時，會於面板中顯示提示。Chrome 無此限制。
- **跨網域影片**：若影片檔案來自其他網域且未開放 CORS，瀏覽器不允許 Web Audio 讀取其音訊。此類影片同樣僅能調整 0%–100% 的音量與播放速度。
- **需先與網頁互動**：瀏覽器規定音訊處理須由使用者操作啟動。若調整音量時出現提示，請點選一下影片畫面，設定將自動套用。
- **高倍速靜音**：播放速度超過約 4× 時，瀏覽器可能自動將聲音靜音，此為瀏覽器本身的行為。
- **Safari 原生全螢幕**：使用 Safari 內建影片播放器進入全螢幕時無法顯示浮動面板；網站自身的全螢幕模式（例如 YouTube）則不受影響。上述兩種情況下鍵盤快捷鍵皆可使用。
- **音訊處理無法中途解除**：影片一旦啟用過音量放大或單聲道，其音訊將持續經由 Web Audio 輸出（恢復 100% 時音質與原始相同）；如需完全還原，請重新整理頁面。

## 技術說明

| 功能 | 實作方式 |
| --- | --- |
| 播放速度 | 設定 `HTMLMediaElement.playbackRate`；若網站自行重設倍速會自動套用回使用者設定，若使用者透過網站介面調整則採用新值。 |
| 音量 0%–100% | 設定 `HTMLMediaElement.volume`，不需使用 Web Audio，適用於所有網站。 |
| 音量 100%–400% | 以 `MediaElementAudioSourceNode` 將音訊接入 Web Audio，並以 `GainNode` 放大。 |
| 單聲道 | 將 `GainNode` 的 `channelCount` 固定為 1（`channelCountMode: "explicit"`），由 Web Audio 以 (L + R) / 2 混音後輸出至兩側聲道。 |
| 相容性偵測 | 以 `AnalyserNode` 量測 Web Audio 是否實際收到音訊訊號，藉此判斷瀏覽器是否支援處理該影片。 |
| 浮動面板 | 以封閉式 Shadow DOM 實作，避免與網頁樣式互相干擾。 |

## 開發

### 專案結構

```
extension/               擴充功能本體（Safari 與 Chrome 共用）
├── manifest.json        Manifest V3 設定檔
├── content.js           內容腳本：影片控制、快捷鍵、浮動面板
├── shared/common.js     共用常數與工具函式
├── popup/               工具列面板
├── options/             設定頁
└── icons/               圖示
scripts/
├── build-xcode.sh       轉換為 Safari Xcode 專案並建置
└── make-icons.py        產生圖示（僅需 Python 標準函式庫與 macOS 內建的 sips）
dev/                     開發用測試頁與測試影片（不包含於擴充功能中）
```

`xcode/` 為建置腳本產生的目錄，已列於 `.gitignore`。

### 本機測試

`dev/` 提供不需安裝擴充功能即可測試的環境。啟動開發伺服器：

```bash
python3 dev/server.py 8765
```

| 頁面 | 用途 |
| --- | --- |
| `http://localhost:8765/dev/harness.html` | 以 `dev/shim.js` 模擬擴充功能 API，於同一頁面測試內容腳本與工具列面板。加上 `?mse=1` 可改以 MSE 串流播放。 |
| `http://localhost:8765/dev/plain.html` | 不含擴充功能程式碼的純影片頁面，供已安裝的擴充功能實際測試。加上 `?mse=1` 可改以 MSE 串流播放。 |
| `http://localhost:8765/dev/webaudio-probe.html` | 檢測目前瀏覽器能否將一般影片檔與 MSE 串流的音訊接入 Web Audio。 |

測試影片僅於左聲道含有 440 Hz 音訊，可用於確認單聲道功能是否生效。

### 重新產生圖示

```bash
python3 scripts/make-icons.py
```

## 隱私權

Video Controller 不會收集、傳送或儲存任何個人資料，亦不會發出任何網路請求。擴充功能僅使用瀏覽器的本機儲存空間保存介面與快捷鍵設定；播放速度、音量等播放設定不會被保存。

擴充功能需要存取所有網站的權限，用途僅限於偵測並控制網頁中的影片元素。
